# Beta Test Scenarios

## 관리자 시나리오

### 1. 로그인

1. `http://localhost:5174/admin` 접속
2. 관리자 워크스페이스 표시 확인
3. 운영 준비 점검 패널이 표시되는지 확인

기대 결과: 관리자 전용 패널이 정상 표시된다.

### 2. AI 상태 확인

1. `AI 상태 점검` 영역 확인
2. 상태 점검 버튼 클릭
3. Gemma 4 응답 및 fallback 미사용 여부 확인

기대 결과: Ollama/Gemma 4가 정상 응답하거나 fallback 상태가 명확히 표시된다.

### 3. 주차 선택

1. `이번 주 핵심 변화` 섹션에서 기준 주차 선택
2. 카드와 라이더 목록이 선택 주차 기준으로 갱신되는지 확인

기대 결과: 완료건수, 운영 라이더 수, 멀티율이 선택 주차 기준으로 표시된다.

### 4. 라이더 위험도 확인

1. `라이더 위험도 요약` 열기
2. 고위험 우선 정렬 확인
3. 추세 배지와 riskLevel 배지 확인

기대 결과: 기존 riskLevel 계산 결과가 그대로 표시되고, 추세 분석은 보조 정보로 표시된다.

### 5. 분석 근거 보기

1. 라이더 카드에서 `분석 근거 보기` 클릭
2. 최근 4주 완료건수 흐름 확인
3. 전주/4주 평균 대비 변화율과 데이터 검수 경고 확인
4. AI 코칭 입력값 미리보기 확인

기대 결과: 관리자 내부 분석 정보가 관리자 화면에서만 표시된다.

### 6. AI 코칭 생성

1. 라이더 카드에서 `AI 코칭 생성` 클릭
2. Gemma 4 생성 또는 기본 템플릿 배지 확인
3. 관리자 메시지와 라이더 메시지 확인

기대 결과: 코드가 계산한 수치 기반 입력값으로 코칭 문구가 생성된다.

### 7. 발송 대기함 추가

1. AI 코칭 결과에서 `발송 대기함에 추가` 클릭
2. 발송 대기함 섹션으로 이동
3. 항목이 추가되었는지 확인

기대 결과: 중복 항목은 추가되지 않고 안내가 표시된다.

### 8. 카톡/문자 문구 복사

1. 발송 대기함 항목에서 카톡 문구 복사
2. 문자 문구 복사
3. 상태가 `복사완료`로 바뀌는지 확인

기대 결과: 클립보드 실패 시 수동 복사용 텍스트가 표시된다.

### 9. 발송완료 처리

1. 발송 대기 항목의 채널과 메모 확인
2. `발송완료` 처리
3. 발송 이력 저장 확인

기대 결과: 항목 상태가 `발송완료`로 바뀌고 발송 이력에 기록된다.

### 10. 운영 로그 확인

1. 운영 로그 섹션 열기
2. AI 코칭, 발송 대기함, 복사, 발송완료 로그 확인
3. 필터를 변경해 로그가 좁혀지는지 확인

기대 결과: 최신순 최근 100개 기준으로 표시된다.

### 11. AI 운영본부 브리핑 생성

1. `AI 운영본부 브리핑` 섹션에서 생성 버튼 클릭
2. 대표 보고용 한 줄 요약 확인
3. 오늘의 우선 조치 3개 확인
4. 상세 브리핑 펼치기

기대 결과: 숫자 집계는 코드 계산값이고, AI는 요약 문장만 생성한다.

### 12. 대표 보고용 복사

1. `대표 보고용 복사` 클릭
2. 복사 완료 또는 수동 복사용 박스 표시 확인
3. 운영 로그에 복사 기록 확인

기대 결과: 대표 보고용 텍스트가 정해진 형식으로 제공된다.

### 13. 백업 파일 다운로드

1. 운영 데이터 백업·복원 섹션 열기
2. `운영 데이터 백업` 클릭
3. 백업 JSON 파일에 AI 코칭, 브리핑, 발송 대기함, 운영 로그가 포함되는지 확인

기대 결과: 실제 운영 전 백업 파일을 확보할 수 있다.

## 라이더 시나리오

### 1. 라이더 화면 접속

1. `http://localhost:5174/rider` 접속
2. 라이더 선택 또는 기본 표시 확인

기대 결과: 라이더 화면이 정상 렌더링된다.

### 2. 본인 정보 확인

1. 본인 주간 요약 확인
2. 공개 가능한 코칭 메시지 확인
3. 성과/정산 안내 문구 확인

기대 결과: 라이더가 이해하기 쉬운 정보만 표시된다.

### 3. 관리자 내부 정보 미노출 확인

아래 문구나 기능이 보이지 않아야 한다.

- 운영 로그
- 발송 대기함
- AI 운영본부 브리핑
- 분석 근거 보기
- 관리자 메모
- 백업/복원
- 운영 준비 점검

기대 결과: 관리자 내부 데이터가 노출되지 않는다.

### 4. 모바일 화면 가독성 확인

1. 모바일 브라우저 또는 DevTools 390px 폭으로 확인
2. 카드 줄바꿈, 버튼 터치 영역, 긴 문구 표시 확인

기대 결과: 가로 스크롤 없이 라이더 정보가 읽기 좋게 표시된다.
