# 엑셀 업로드 컬럼명 권장 형식

라이더 코칭센터는 쿠팡이츠 주차별 상세 엑셀의 컬럼명이 조금 달라도 업로드를 시도합니다. 운영 안정성을 위해 아래 이름을 우선 권장합니다.

## 권장 컬럼명

- 라이더명: `라이더명`
- 완료건수: `완료건수`
- 배달타입: `배달타입`
- 시간대: `피크타임` 또는 `해당 구간타임`
- 픽업/배달 지역: `픽업지역`, `배달지역`

## 라이더명 허용 예시

`라이더명`, `기사명`, `배달파트너명`, `배달파트너`, `파트너명`, `이름`, `수행자`, `배달원명`, `배달원`, `riderName`, `rider_name`, `driverName`, `driver_name`

라이더명 컬럼을 찾지 못하면 업로드 미리보기와 데이터 검수 화면에 “라이더명 컬럼을 찾지 못했습니다. 엑셀의 컬럼명을 확인해주세요.” 경고가 표시됩니다.

## 배달타입 허용 예시

- 단건: `단건`, `단건배달`, `단건 배달`, `SINGLE`, `single`, `1건`, `일반`
- 멀티: `멀티`, `멀티배달`, `멀티 배달`, `멀티1`, `멀티 1`, `멀티배달1`, `멀티배달 1`, `멀티2`, `멀티3`, `멀티4`, `M1`, `M2`, `M3`, `M4`, `multi`, `MULTI`
- 숫자만 있는 값: `1`, `2`, `3`, `4`는 각각 `멀티배달1~4`로 해석합니다.

빈 값이나 해석할 수 없는 값은 업로드를 중단하지 않고 `확인 필요`로 분류합니다. 완료건수에는 포함되지만 배달타입 검수 경고에 원본값과 행 번호가 남습니다.

## 오류 확인 방법

1. `/upload`에서 파싱 미리보기를 실행합니다.
2. 미리보기의 업로드 결과 요약에서 총 행 수, 정상 파싱 행 수, 라이더명 인식 행 수, 배달타입 확인 필요 행 수를 확인합니다.
3. `/validation`에서 주차를 선택하고 “이상치 및 오류 목록”을 확인합니다.
4. 목록은 화면 확인용으로 상위 30개까지만 표시됩니다. 전체 오류 수는 요약 카드의 카운트를 기준으로 봅니다.
