# Release Notes: Beta MVP

## 현재 버전

Beta MVP

## 주요 기능 요약

- 엑셀 업로드 기반 주차별 라이더 운영 데이터 분석
- 관리자 대시보드 핵심 지표와 라이더 위험도 요약
- AI 코칭 생성 및 이전 코칭 이력 보기
- 고위험 우선 정렬과 관리자 액션 체크리스트
- 주간 AI 브리핑과 월간 운영 리포트
- 최근 4주 추세 분석, 분석 근거 보기, 데이터 검수 경고
- 카톡/문자 수동 발송용 문구 복사
- 발송 대기함, 발송 완료 처리, 발송 이력
- AI 운영본부 브리핑과 대표 보고용 복사
- 운영 로그, Health Check, 운영 준비 점검
- 운영 데이터 백업/복원
- 모바일 가독성 개선과 PWA 기본 manifest

## 문자 발송 API 상태

실제 문자 발송 API는 아직 미연동이다. 현재 기능은 카톡/문자 문구를 복사하고 운영자가 수동으로 발송 상태를 관리하는 단계다.

## 로컬 Gemma 4 사용 조건

- Ollama 실행 필요: `http://localhost:11434`
- 모델명: `gemma4:e2b`
- 권장 설정:
  - `OLLAMA_NUM_CTX=1024`
  - `OLLAMA_NUM_PREDICT=300`
  - `OLLAMA_TIMEOUT_MS=30000`
- Gemma 4는 숫자를 계산하지 않고, 코드가 계산한 값에 대한 요약/설명/브리핑 문구만 생성한다.

## 관리자 전용 기능

- AI 코칭 생성/재생성
- AI 상태 점검
- 분석 근거 보기와 데이터 검수 경고
- 관리자 액션 체크리스트
- 주간 AI 브리핑 생성
- AI 운영본부 브리핑 생성
- 월간 운영 리포트 생성
- 발송 대기함과 발송 이력 관리
- 운영 로그 보기
- 백업/복원 및 CSV/JSON 내보내기
- 운영 준비 점검과 베타 테스트 준비 상태 확인

## 라이더에게 노출되는 기능

- 본인 주간 요약
- 본인에게 공개 가능한 코칭 메시지
- 본인 성과/정산 관련 안내
- 라이더 화면 테스트용 선택 기능

라이더 화면에는 운영 로그, 발송 대기함, 관리자 내부 메모, 분석 근거, 운영 준비 점검이 노출되면 안 된다.

## 알려진 제한사항

- 실제 로그인/권한 시스템은 간이 role 기반 구조다.
- DB는 아직 붙이지 않았고, 운영 데이터는 `backend/data/*.json`에 저장한다.
- 실제 문자/카톡 자동 발송은 지원하지 않는다.
- 브라우저 클립보드 권한이 막히면 수동 복사용 박스가 표시된다.
- Ollama 또는 Gemma 4 응답 실패 시 기본 템플릿을 사용한다.
- `backend/data/*.json`은 git 제외 대상이므로 별도 백업이 필요하다.
